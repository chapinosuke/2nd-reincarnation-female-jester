# 実装指示書：もくじを章（アーク）アコーディオンに

## 背景・目的
トップ（`web/src/pages/index.astro`）のもくじが、20話を大きなカードで縦一列に並べていて約2940px（3画面弱）と長すぎる。
全20話を4つの章（アーク）に分け、`<details>/<summary>` のアコーディオンで開閉できるようにして、初期表示では全体像が一目で見渡せるようにする。
**話数・タイトル・リンク先は一切変えない。並べ方だけを変える。**

## デザイン準拠
`デザイン/トークン.md` に完全準拠。新しい色・フォント・依存を増やさない。既存の `.sheet` `.hanko` `.tide-rule` `.stamp-in` を流用する。

## アーク定義（この配列を単一の情報源にする）
`web/src/lib/chapters.ts` に以下をexportで追加（index.astroから import して使う。章題を後で直すのがここ1箇所で済むように）：

```ts
export interface Arc { no: string; title: string; from: number; to: number; }
export const ARCS: Arc[] = [
  { no: '一', title: '遊び人、目覚める', from: 1,  to: 3  },
  { no: '二', title: '書類と、日銭と',   from: 4,  to: 8  },
  { no: '三', title: '勇者だらけの街',   from: 9,  to: 12 },
  { no: '四', title: '峠越え',           from: 13, to: 20 },
];

/** 章ごとに話をまとめる。範囲外の話が出た場合は最後の章に寄せる（将来の増話に耐える） */
export function groupByArc(chapters: ChapterMeta[]): { arc: Arc; items: ChapterMeta[] }[] { ... }
```
`groupByArc` は ARCS の各章について `from<=number<=to` の話を集める。どの章にも入らない話（21話以降など）は最後の章に含める。空の章は出力しない。

## マークアップ（index.astro の #chapters セクションを差し替え）

CONTENTS 見出し（英字eyebrow「CONTENTS」＋「もくじ」）は現状のまま残す。その下のリスト部分を以下に置き換える：

- 章ごとに1つの `<details class="arc ...">`。**先頭の章のみ `open` 属性**を付ける
- `<summary>`（クリックで開閉。`list-style:none`・`cursor:pointer`・キーボード操作可）の中身：
  - 左：小さめの縦書き朱印で「章数（漢数字）之章」。既存 `.hanko` を流用（サイズは text-[10px]〜xs 相当で小さく）
  - 中央：章題（`font-display text-tide-900`、例「遊び人、目覚める」）＋その下に細く範囲「第一〜三話」（`text-xs text-ink-500`。`toKanji`で漢数字化）
  - 右：開閉インジケータ `▽`（閉じ）／`△`（開き）。`.arc[open] .marker-closed{display:none}` のようなCSSか、`▾` を `details[open]` で回転。`aria-hidden`
  - summary全体を `.sheet` のカードにして、章の見出しらしく。hoverで軽く持ち上げ（既存の hover:-translate-y-0.5 を流用）
- `<details>` の中身：その章の話のリスト。**現行の各話カードより高さを詰める**：
  - 各話は横並びの1行（`.sheet` かボーダー区切りのどちらか。トークンに合う方＝軽くしたいので、章の中は `.sheet` を使わず、細い罫 `border-b border-gilt-400/15` で区切る行にする）
  - 行の左に小さな判子（`.hanko` text-[10px]、「第N話」）、右に `font-display text-tide-900` のタイトル。hoverで seal-600 に。padding は `py-3`（現行 py-5 より詰める）
  - 各話は現行同様 `/chapter/{slug}` にリンク

## 捺印アニメの遅延バグ修正（重要）
現行は判子の `stamp-in` の `animation-delay` を全20話通しの `i*70ms` にしているため、末尾（19・20話）が最大1.4s遅延し、スクロール到達時にまだ出ていないことがある。
**修正**：animation-delay は「章の中でのindex」で計算する（各章高々8話なので最大560ms）。章見出しの朱印には delay 0。これで折りたたみを開いた章の判子も速やかに捺印される。

## 「つづきから読む」との連携（任意・できれば）
`last-read` がある場合、その話を含む章を初期状態で `open` にできると親切（先頭章に加えて）。実装は、全 `<details>` に `data-from`/`data-to` を持たせ、index末尾のインラインスクリプトで last-read の number を含む章に `open` を付与する。難しければ先頭章openのみでよい（必須ではない）。

## アクセシビリティ / モーション
- `summary` はネイティブでキーボード操作可能。`list-style:none` と `::-webkit-details-marker{display:none}` でデフォルト三角を消す
- `prefers-reduced-motion` 時に開閉やstamp-inのモーションを抑制（既存のreduced-motion指定を継承。details自体のアニメは付けないのでOK）
- summaryに適切なフォーカスリング（既存 :focus-visible を継承）

## 受け入れ基準
1. `cd web && npm run build` 成功（警告なし）
2. トップの #chapters が4つの章に分かれ、初期は一之章だけ開いている。もくじセクションの初期高さが現行（約2940px）の半分以下
3. 各章を開くと中の話が現行と同じ順・同じタイトル・同じリンク先で表示される（`/chapter/01`〜`/chapter/20`）
4. 全20話が4章に過不足なく含まれる（1-3 / 4-8 / 9-12 / 13-20）。第十九・二十話の判子も開けばきちんと表示される
5. 375px幅で横スクロールが出ない。スマホで折りたたみが機能する
6. 章タイトルは `chapters.ts` の ARCS を1箇所直せば変わる
7. 既存の他ページ・ヒーロー・入口カード・フッターは無変更

- コミットはしない（検収後にFableが行う）
