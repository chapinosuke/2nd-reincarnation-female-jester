# デザイントークン（第1部・正典）

サイト全体の配色・書体・部品の正典。実装は `web/tailwind.config.mjs` と `web/src/styles/global.css` に既に反映済み。
新しいページ・部品を作るときは必ずこの文書に従うこと。ここにない色・書体を勝手に増やさない。

参照元：『葬送のフリーレン』公式サイトの配色・書体運用（湖水の青緑×森の緑×古金、白地＋粒状ノイズ、明朝見出し＋英字キャップス）。

## 2. 書体

| 役割 | フォント | 用途 |
|---|---|---|
| serif（本文） | Noto Serif JP | 長文本文。行間2.05・字送り0.04em・palt |
| display（見出し） | Zen Old Mincho | h1〜h3・話タイトル・判子 |
| eyebrow（英字） | Cinzel | 英字キャップスのアイキャッチ。字間0.25〜0.5em |

Google Fonts読込は `Base.astro` に集約。ウェイトを増やすときもBase.astroのみ変更。

## 3. 部品（global.css実装済み）

| クラス | 見た目 | 使いどころ |
|---|---|---|
| `.sheet` | ギルドの書類。生成りのカード＋湖水×金の細縁 | カード全般。目次行・本文紙面・ナビカード |
| `.hanko` | 縦書き朱印。-2.5度傾き＋朱肉かすれマスク | 話数表記。「第◯話」以外に乱用しない |
| `.tide-rule` | 湖水→森の横グラデ罫（#0f8c8d→#238c68） | ページ上端・区切り罫 |
| `.stamp-in` | 捺印モーション（拡大→定位置） | 判子の登場時。スタッガー70ms |
| `.fade-in` | 8px下から浮上 | セクション登場時 |
| 紙ノイズ | body背景のfractalNoise SVG＋湖水のラジアルグロー | 全ページ共通。追加ページでも継承される |

## 4. 運用ルール

1. 新ページも「紙の上の書類」メタファーを守る。コンテンツは`.sheet`に載せ、地は必ずpaper-50
2. 見出し階層：英字キャップス（eyebrow/gilt-500）→和文見出し（display/tide-900）→本文（serif/ink-800）の三段
3. 角丸は最大4px。影はtide-900系の色付き影のみ（黒影禁止）
4. アニメーションは stamp-in / fade-in の2種で足りる。prefers-reduced-motion対応を必ず継承
5. 画像には `ring-1 ring-gilt-400/50` ＋ tide-900系の落ち影
