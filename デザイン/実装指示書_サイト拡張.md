# 実装指示書：サイト拡張（Phase 1配線＋Phase 2＋Phase 3）

実装担当への指示書。設計・文面はすべてこの文書で確定済み。**文面の改変は禁止**（誤字修正のみ可）。
迷ったら `デザイン/トークン.md` → `デザイン/アセット台帳.md` → 既存2ページ（index.astro / chapter/[slug].astro）の順に参照。

## 前提

- 作業ディレクトリ：`web/`（Astro + Tailwind。`npm run build` が通ることを常に維持）
- デザインは `デザイン/トークン.md` に完全準拠。色・書体・部品を新規に増やさない
- 全ページ共通：paper地・`.sheet`カード・eyebrow（英字）→display（和文見出し）→serif（本文）の三段構成
- `prefers-reduced-motion` 対応を新規アニメーションにも必ず適用
- 配置済みアセット：`web/public/favicon.svg`（朱印「遊」）、`web/public/pattern-ale.svg`（泡紋様）

## 1. ナビゲーション整備

### Base.astro のフッター

## 4. 世界観ページ `/world`

`web/src/pages/world.astro`。枠組み：「灰鷲ギルド　ハイベル支部の資料室」体裁。

- ヘッダー：上部固定ナビ（中央英字「WORLD」）
- 見出し：eyebrow「WORLD」＋display「世界観」＋補足「――灰鷲ギルド　ハイベル支部・資料室蔵」
- 各セクションは `.sheet` カード。見出しは「一、二、三…」の漢数字＋display

### 文面（確定稿・改変禁止）

**一、勇者は自称である**
> この世界において「勇者」は称号ではない。剣を持ち、名乗れば、その日から誰でも勇者である。ゆえに世界には勇者が溢れ、酒場は名乗りに拍手をしない。魔王は討伐されても、いずれ戻る。人々はそれを、季節のようなものとして受け入れている。ギルドの掲示板には今日も二枚、貼りっぱなしの依頼がある。「魔王討伐　常設　達成者なし」「古竜討伐　常設　高額報酬　達成者なし」。誰も、気に留めない。

**二、通貨 ―― モンメリーとピィ**
> 上位通貨モンメリーと、日常の小銭ピィ。**1モンメリー＝10ピィ**。屋台のスープ一杯がピィ2枚。これが庶民の腹の基準である。
>
> ミアはこの「モンメリー」という響きに、何かが引っかかっている。換算した先にあったはずの通貨の名前を、どうしても思い出せない。

**三、物価の目安（資料室調べ）**
表組みで：
| 品目 | 価格 |
|---|---|
| 屋台のスープ一杯 | ピィ2枚 |
| 酒場で一晩の豪飲 | ピィ12〜13枚 |
| 宿代（居眠り山羊亭・一泊・一行分） | ピィ6枚 |
| 臨時雇いの日当（相場より大幅に安い実績値） | ピィ2枚 |
| セクハラ罰金（パーティー内制度・一件） | モンメリー2枚 |

**四、灰鷲ギルド　ハイベル支部**
> 依頼の斡旋所であり、書類の城である。規約はひとつ覚えておけばいい。**四人以上のパーティーでなければ、まともなランクの依頼は受けられない。**人数さえ揃えば、職業は問わない。受付のドリスは言った。「あんたが何ができるかは、書類は問わない」。バニー衣装は、職業証の正装として認められている。前例があるらしい。

**五、罰金制度**
> パーティー内の私的制度。ゴルドの手が動いた場合、一件につきモンメリー2枚。セラが帳簿に記録し、マルヴァへ送金される。口頭のみ（「腰の動きが――」等）はノーカウント。抑止力として設計されたが、抑止できているかは帳簿が知っている。→ くわしくは[帳簿](/ledger)へ

**六、ハイベルの暮らし**
> 自治区ハイベル。ミアの職場は酒場『陽気な冒険者』、看板メニューは白ひげチーズ。パーティーの宿は街外れの『居眠り山羊亭』、看板山羊のクルルの瞼は経済指標と呼ばれるが、当てになった例しがない。

### 6-4. 換算機「ピィでいくら？」

`.sheet` 内の小さなインタラクティブ（vanilla JSの`<script>`、依存追加禁止）。

- 入力：数値フィールド＋単位切替（ピィ／モンメリー）
- 出力（リアルタイム更新）：スープ○杯／宿○泊（一行分）／臨時日当○日分／ゴルドの罰金○件分
- 換算値：スープ=2ピィ、宿=6ピィ、日当=2ピィ、罰金=20ピィ。小数は一位まで（例：12ピィ→スープ6杯、宿2泊、罰金0.6件分）
- プリセットボタン2つ：「モンメリー50枚（破格の依頼）」「モンメリー28枚（罰金の累計）」
- 見出し：「換算機 ――スープ何杯分？」／注記「基準：屋台のスープ一杯＝ピィ2枚」

## 7. 読書体験

### 7-1. 文字サイズ切替
- 章ページの上部固定ナビ右端（現在の空スペーサー`w-14`の位置）に「字」トグル：小／中／大の3段階
- `localStorage('reader-font-size')` に保存。`<html data-font-size="s|m|l">` を切り替え、CSSで `.prose` のfont-sizeを 0.95rem／1.125rem（現状）／1.3rem に
- FOUC防止のため、保存値の適用はheadのインラインスクリプトで行う

### 7-2. 読了位置（続きから読む）
- 章ページ表示時に `localStorage('last-read')` へ `{slug, number, title}` を保存（インラインスクリプト）
- index.astroのヒーローCTA横に「つづきから読む」ボタンを追加。`last-read` がある場合のみ表示（クライアントサイドで表示切替）し、保存された章へリンク。スタイルは「第一話から読む」と同型の枠線版（tide枠）
- 保存がない初回訪問では非表示（レイアウトが崩れないこと）

## 8. OGP画像＋メタ情報

### 8-1. OGP画像生成（1200×630 PNG）
Python3＋PIL（インストール済み）でスクリプトを書き、`web/public/ogp.png` を生成する。スクリプトは `デザイン/scripts/make_ogp.py` として保存（再生成可能に）。

レイアウト：
- 地：paper-50 `#fbfaf4`。上端に3pxのtide→sageグラデ罫、下端にも同じ罫
- 右側：`assets/key-visual/mia-mirror-shock-pajamas.jpeg` を高さいっぱいにトリミング配置（右40%領域）。左端をpaper-50へのグラデでなじませる
- 左側：縦組みは不要。上から
  - 英字「TRANSMIGRATION COMEDY」（Cinzelがなければ省略可、gilt-500）
  - タイトル「2度目の転生は／女遊び人でした」2行（ヒラギノ明朝 W6、tide-900 `#0d3335`、72px前後）
  - コピー「戦えない。魔法も使えない。装備はバニーガール衣装のみ。」（ヒラギノ明朝、ink-700、28px前後）
- 左下に朱印風の正方形（seal-500の枠＋「遊」、favicon.svgと同じ意匠）
- フォント：`/System/Library/Fonts/ヒラギノ明朝 ProN.ttc`（PILでindex指定）

### 8-2. Base.astro のメタ拡張
- Propsに `ogImage?: string`（既定 `/ogp.png`）と `ogType?: string` を追加
- `og:title` `og:description` `og:image` `og:type` `twitter:card=summary_large_image` を出力
- `<link rel="icon" href="/favicon.svg" type="image/svg+xml">` を追加
- サイトURLは未確定のため、`astro.config.mjs` に `site` は**追加しない**。`og:image` は相対パスでよい（デプロイ時にsiteを設定して絶対URL化する旨のTODOコメントをBase.astroに残す）

## 9. 受け入れ基準

1. `cd web && npm run build` が警告なしで成功する
2. `npm run dev` で全ページ（/ /characters /world /ledger /gallery /chapter/01）を開き、コンソールエラーがない
3. 文字サイズ切替がリロード後も保持される。「つづきから読む」が章を開いた後のトップに現れる
4. 換算機：「モンメリー50枚」プリセットで「スープ250杯／宿83.3泊／日当250日分／罰金25件分」と表示される
5. チャートの数値が本文書のデータ表と一致する
6. モバイル幅（375px）で全ページの横スクロールが発生しない
7. `assets/archive/` の画像がどこにも使われていない
8. 既存の章ページ・もくじの見た目が（ナビ・トグル追加以外）変わっていない
