# 第1巻 一気執筆の指示

## タスク

「2度目の転生は女遊び人でした」**第1話〜第20話（各話5000字前後）を、構成表に沿って一気に執筆する。**
既存の `本編/第01話.md`・`本編/第02話.md` は**旧稿**であり、全面的に書き換える。**基本はコミカル。**

## 旧稿（第1〜2話）の扱い

- 旧稿は素材。声の4層、テンポ、ギャグの密度など**良い部分は引き継ぎ、演出・描写・構成は自由に作り直してよい**
- ただし `設定/確定事実・伏線.md` の第1〜2話の項目は「**新稿でも成立させるべき要素リスト**」。後続話と設定がこれに依存しているため、要素そのものは必ず新稿にも入れる（例：身体と意識の分離、シチュー事件→「役に立たねえ」→前世（仮）フラッシュバック、「後ろ、取られてますよ」の機転、モンメリー＝もんめの違和感、「効かせる女」、罰金制度、不本意な四人目登録、声4層の出揃い）
- タイトルは変更してよい（「第◯話　タイトル」の形式は維持）
- 新稿確定後、台帳の第1〜2話項目を新稿の内容で更新する

## 手順

1. **まず以下を全て読むこと**(これが正典。迷ったらこの順で優先）：
   - `設定/構成_第1巻.md` — 話別プロット・話型テンプレート・縦糸2本。執筆はこれに従う
   - `設定/執筆ルール.md` — 文字数・出力形式・NG事項・第1話の目覚め演出
   - `設定/文体設計.md` — 二層文体（軽やかな語り＋考察系独白）
   - `設定/主人公.md` — 声の4層構造と運用ルール（第4層＝関西弁は1話1回まで）
   - `設定/パーティー.md`／`設定/キャラクター_ヴォルム.md`／`設定/キャラクター_マルヴァ.md` — 口調サンプル・別の顔の開示予定に従う
   - `設定/経済と制度.md` — 通貨・物価・罰金。**セラの発言に出る金額は必ず計算を合わせる**
   - `設定/魔王と均衡.md` — 開示ペース厳守（巻1は3話・12話・18話の3点だけで匂わせる）
   - `設定/確定事実・伏線.md` — 台帳。第1〜2話の要素リストと未回収伏線を確認
   - `設定/コンセプト.md`／`設定/世界観.md` — 作品の二重構造と考察未満ルール
   - `本編/第01話.md`・`本編/第02話.md` — 旧稿（素材として読む）
2. 第1話から第20話まで、構成表の話別プロットどおりに**順番に**執筆する。出力は `本編/第01話.md` 〜 `本編/第20話.md`（第1〜2話は上書き）。形式：1行目に「第◯話　タイトル」、以降は本文のみ。地の文は全角スペースで字下げ。解説・まとめ・次回予告は書かない
3. 1話書き終えるごとに `設定/確定事実・伏線.md` を更新する（新しい固有名詞／確定事実／張った伏線／次話への持ち越し状態）。未設定の固有名詞（街、ギルド、酒場の店主、老農夫、ザック隊の取り巻き2名など）は執筆時に命名し、必ず台帳に記録する
4. 3〜4話書くごとに一度立ち止まり、直近の話を次の3点で点検してから先へ進む：①執筆ルールのNG事項 ②金額の計算整合 ③声4層の運用（第4層は1話1回まで、出たら本人が動揺する）
5. **全話完了後、HTMLで出す**：`cd web && npm install && npm run build` で静的HTML（`web/dist/`）を生成。確認用プレビューは `npm run dev`。webは `本編/*.md` を自動で読み込むので、本編さえ正しければ追加作業は不要
6. サブエージェント（ストーリーテラー／キャラクターデザイナー／文体エディター等）を並行活用する場合も、**全員に上記の正典ファイル群を読ませる**こと
7. コミットはユーザーに確認してから

## トーンの最重要事項

- **基本はコミカル**。コメディの勢いを最優先（序盤8:2 → 中盤7:3 → 終盤5:5、ラストはコメディで締める）
- 各話は話型テンプレート（一依頼一出会い）を骨格にする：依頼か出会いが一つ／ミアの「効く」瞬間が一つ／メンバーの別の顔か関係の前進が一つ／違和感か伏線が一つ／軽口で締め
- ギャグエンジンは4基：ゴルドの手癖と罰金送金／セラの帳簿と正論／アルトの謝罪癖／ミアの声4層。毎話どれかを回す
- **NG絶対厳守**：転生の断定／神・管理者・システムの明示／考察の結論づけ／説教臭い独白／主人公無双／都合のいいハーレム／露骨な性描写／現代ネットスラング多用／読者へのメタ発言
- ミアは巻を通して「馴染めない → 別の顔を見て馴染む」。20話の宴で「四人目」が書類でなく実感になる
- 18話の関西弁漏出は巻1で最大の漏出。19話の生還は「効いたのか、竜の気まぐれか」を結論づけない
